## Funcionalidades

O sistema permite realizar conversões entre as seguintes bases numéricas:

### Decimal
- Decimal -> Binário  
- Decimal -> Hexadecimal  

### Binário
- Binário -> Decimal  
- Binário -> Hexadecimal  

### Hexadecimal
- Hexadecimal -> Binário  
- Hexadecimal -> Decimal
